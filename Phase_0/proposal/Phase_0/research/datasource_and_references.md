# AgroMarket Phase 0 – Research and Data Source

## Data Source

AgroMarket plans to use agricultural data from the Food and Agriculture Organization of the United Nations (FAOSTAT).

Website: https://www.fao.org/faostat/en/

FAOSTAT provides agricultural statistics that can support research and analysis of agricultural production and related information.

## Project Innovation

AgroMarket plans to combine a web-based agricultural marketplace with Oracle Database and PL/SQL. The system will allow farmers to list agricultural products and customers to browse and order products.

## Planned Technologies

- PHP
- HTML
- CSS
- JavaScript
- Oracle Database 21c XE
- PL/SQL
